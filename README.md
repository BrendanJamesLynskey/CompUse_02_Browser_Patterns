# CompUse 02 — Browser Agent Patterns

A practical deep-dive into browser-native agent architectures: Browser-Use (Python library, AXTree + screenshot hybrid), Playwright-based agent scaffolding, Steel's remote-browser-as-a-service infrastructure, DOM extraction strategies (accessibility tree filtering, interactive-element detection, set-of-marks), screen-capture versus DOM-only trade-offs, WebArena and Mind2Web evaluation benchmarks, captcha/anti-bot mitigations, stateful session management (cookies, auth, persistence), cloud pricing models, common failure modes, and recovery patterns.
